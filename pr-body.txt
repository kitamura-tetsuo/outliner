This PR fixes an issue where clicking the "Add Database" button in the main toolbar caused the editor to lose focus, which could lead to databases being inserted in unexpected locations or failing to insert entirely.

### Issues
- The "Add Database" button did not have the `data-keep-editor-focus` and `preventEditorBlur` attributes.
- Clicking the button caused the global textarea to blur, breaking the context needed by `commandPaletteStore.insert("yjstable")`.

### Changes
- Added `data-keep-editor-focus` attribute to the "Add Database" button in `client/src/components/Toolbar.svelte`.
- Added `onpointerdown={preventEditorBlur}` to the "Add Database" button.
- Mitigated flakiness in `col-caret-rebase-4706cafe.spec.ts` by explicitly focusing the textarea before polling for cursor changes.

### Verification Results
- All unit tests and e2e tests passed.
- Linter and type checker passed.
- The button now retains editor focus when clicked.
