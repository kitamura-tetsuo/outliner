[Issues]
Several UI components in the `client/src/components/` directory used boolean expressions directly for `aria-*` attributes (e.g. `aria-selected`, `aria-pressed`, `aria-disabled`). While modern Svelte versions gracefully handle boolean stringification, adhering to explicit string literals (e.g. `"true"` or `"false"`) for ARIA enumerated attributes is a stricter, safer standard that aligns with project conventions, ensures accessibility correctness across different DOM implementations, and avoids linter/type-checker ambiguities.
