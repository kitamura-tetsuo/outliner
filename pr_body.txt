[Issues]
During test runs (`vitest` in jsdom), components utilizing `echarts.init()` (specifically `GraphView` and `TableChartPanel`) generate a console warning: `[ECharts] Can't get DOM width or height`. This occurs because jsdom doesn't fully support layout metrics like `clientWidth` and `clientHeight` without being explicitly set.

[Changes]
- Modified `client/src/components/GraphView.svelte` to provide fallback dimensions (width: 800, height: 400) to `echarts.init()` if `graphDiv.clientWidth/Height` are 0.
- Modified `client/src/components/yjstable/TableChartPanel.svelte` to provide fallback dimensions (width: 400, height: 300) to `echarts.init()` if `chartDiv.clientWidth/Height` are 0.

[Verification Results]
- All tests pass, and the previously logged `[ECharts] Can't get DOM width or height` console warnings no longer appear.
- Verified that `npm run test:base`, `npx svelte-check`, and `npm run build` finish successfully.
